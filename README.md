# GreenSpot – školska eko-inicijativa

Responzivna prezentacijska web-stranica izrađena pomoću HTML5, CSS3 i JavaScripta.

Razvojni rad se nalazi na branchu `feature/greenspot-solo`. Nemojte spajati u `main` prije pregleda nastavnika.

Detaljna dokumentacija, upute za pokretanje i prezentaciju nalaze se na razvojnom branchu.
